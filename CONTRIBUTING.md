# Contributing

[Project home](README.md) · [Full contribution guide](docs/08-contributing-and-release/how-to-contribute.md)

You can help by improving an explanation, checking a hand calculation, adding a clear example, reporting a problem or changing code.

Start with [ways for students and developers to help](docs/08-contributing-and-release/how-to-contribute.md). Explain what changed, why it helps and how you checked it.

Use simple English, state units and keep data origins clear. Do not claim an experiment or a successful check that did not happen.

Before submitting, run the relevant [checks](docs/07-testing-and-evidence/verification.md) and update affected documentation. Read [AI and authorship guidance](docs/08-contributing-and-release/ai-and-authorship.md) and [security guidance](SECURITY.md).
