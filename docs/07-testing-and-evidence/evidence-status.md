# What has and has not been checked

[Project home](../../README.md) · [Documentation map](../README.md) · [Section guide](README.md)


A result is useful only when its source and limits are clear. This page separates four kinds of progress.

| Area | Current evidence | What it does not prove |
|---|---|---|
| Software verification | Analytical tests, OpenSees comparisons and app checks passed | Every possible model is correct |
| Synthetic research | Full grid was run with saved settings and seed | Agreement with a real beam |
| Physical validation | Importer, templates and protocol are ready; actual findings are pending | That a physical experiment took place |
| External reproduction | No run by another person is recorded | Independent usability or reproducibility |
| Public release | [Source is published on GitHub](https://github.com/md-ishtiak-ahmed-sajib/Python-FEM-Structural-Solver) | Physical validation, independent reproduction or broad adoption |

The full study was regenerated from the current source on 2026-09-01. It has 2,304 configurations with 200 planned trials each. Of those configurations, 192 are unidentifiable; 422,400 trials receive estimates. These remain synthetic calculations, not physical validation.

## Use the right words

**Analytical** means based on a mathematical solution. **Synthetic** means generated by a calculation. **Reference comparison** means another program solved a matching model. **Measured** means a real instrument recorded a real test.

OpenSees is an independent numerical implementation. Running it on the same PC is not the same as another person reproducing this repository.

## Honest conclusions

We can say that the checked examples agree under matching assumptions. We can show how wrong support assumptions affect the synthetic estimates.

We cannot claim experimental agreement, damage detection, structural safety, broad adoption, publication novelty or admission success.

Keep limitations beside results, not hidden in a separate disclaimer.
